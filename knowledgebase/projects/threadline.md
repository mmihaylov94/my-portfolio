## Summary

Threadline is a moderated community forum platform with category discussions, threaded posts, voting/favorites, reporting, and moderation workflows.

## Problem Solved

Communities need structured discussions with moderation and role-based control.

## Solution

- Category-based and threaded discussions.
- Voting and favorites.
- User profiles, search, and sorting.
- Reporting system and moderation dashboard.

## Technologies

- CodeIgniter 4
- PHP
- PostgreSQL
- HTML
- JavaScript
- CSS
- Bootstrap 5

## Outcome

Demonstrates role-aware moderation workflows, authentication patterns, and scalable forum architecture.
