## Summary

Taskflow is a Kanban-style project management tool for team planning and delivery tracking.

## Problem Solved

Teams need board-based workflow visibility, collaboration history, and controlled access for execution tracking.

## Solution

- Boards, lists, and cards with drag-and-drop workflow.
- Assignments, due dates, labels, and comments.
- Activity history and role-based access.

## Technologies

- Laravel
- PHP
- Vue
- Tailwind CSS
- REST API

## Outcome

Improves team visibility and delivery tracking in Kanban workflows.
