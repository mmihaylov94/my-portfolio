## Summary

OmniRetail is a retail operations platform that centralizes products, inventory, orders, checkout, and role-based operational workflows.

## Problem Solved

Retail operations become inefficient when product, stock, and order management are fragmented across tools.

## Solution

- Consolidates POS workflows and stock tracking.
- Supports order lifecycle management.
- Includes role-based access and sales reporting support.

## Technologies

- CodeIgniter
- PHP
- MySQL
- HTML
- JavaScript
- React
- Tailwind CSS

## Outcome

Centralizes retail operations and reduces stock/sales administrative overhead.
